# Shridhar Kumbhar — Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a browser.

## Personalize before publishing
- Replace the placeholder GitHub links on each project card with the actual repository URLs.
- Update the LinkedIn link with your profile URL.
- Add a resume PDF link if you want a downloadable resume.
- Review the skills, training, internship, and project descriptions. Keep only details you can confidently explain.
- Add project screenshots in an `assets` folder if available.

## Publish free with GitHub Pages
1. Create a public GitHub repository, for example `shridhar-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL shown in the Pages section.

Your public portfolio URL will look similar to:
`https://YOUR-GITHUB-USERNAME.github.io/shridhar-portfolio/`
